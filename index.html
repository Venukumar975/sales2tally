[ KNOWLEDGE BASE ]

FREQUENTLY ASKED QUESTIONS

How do I install SALES2TALLY on my computer? +

Simply download SALES2TALLY_Setup_v1.0.exe, run the installer, and follow the standard on-screen setup steps. A desktop icon named SALES2TALLY will be created automatically.

Does SALES2TALLY send my financial data to any server? +

No. SALES2TALLY runs 100% locally on your machine. All calculations, parsing, and XML generation happen completely offline in your local environment.

How do I import the generated XML into Tally Prime? +

In Tally Prime, navigate to Alt+O (Import) > Transactions > XML Format, select the generated XML file, and press Enter. All invoices and vouchers will be imported seamlessly.

Can it handle items with different GST tax rates on the same invoice? +

Yes. The multi-tax parsing engine groups ledger entries by GST rate and generates proper CGST, SGST, and IGST breakdowns for multi-item and multi-rate vouchers.
